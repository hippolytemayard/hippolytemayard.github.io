teeth-3d-mesh-segmentation

MeshSegNet for automated tooth labelling on raw intra-oral 3D scans — 3DTeethSeg22 challenge (MICCAI 2022).

Problem. Label every tooth on a raw intra-oral scanner mesh (upper and lower jaw) with no preprocessing — a prerequisite for orthodontic planning and aligner design.

Approach. Implementation of MeshSegNet (multi-scale graph-constrained mesh feature learning) on the 3DTeethSeg22 challenge data: 1,800 scans from 900 patients, 33 labels (background + 32 FDI teeth). Per-cell features (coordinates, normals, relative position), two graph-constrained learning modules at different radii, dense cell-wise prediction, then graph-cut refinement.

Left: ground truth vs prediction on a held-out jaw. Right: MeshSegNet architecture.

Takeaway. The hard part is not the network but the mesh pipeline: decimation to a fixed cell budget, consistent normals, and keeping train/test splits patient-disjoint (upper and lower jaws of the same patient must land on the same side).
