chest-x-ray-generative-models

Unconditional generation of chest X-rays with a denoising diffusion probabilistic model (DDPM), trained at 128×128 on a public chest radiography dataset.

What this is. Unconditional generation of chest X-rays with a Denoising Diffusion Probabilistic Model, trained at 128×128 on a public chest radiography dataset (Kaggle).

Samples from the trained model.

Scope and credits. The U-Net and the Gaussian diffusion code are adapted from lucidrains/denoising-diffusion-pytorch. This repository adds:

  • single-channel (grayscale) training on radiographs,
  • a dataset and normalization pipeline for the X-ray images,
  • a YAML-driven training entry point,
  • an inference notebook and a released checkpoint.

No quantitative evaluation (FID, downstream task) is reported.

References. J. Ho, A. Jain, P. Abbeel. Denoising Diffusion Probabilistic Models. NeurIPS 2020. U. Sait et al. Curated Dataset for COVID-19 Posterior-Anterior Chest Radiography Images (X-Rays). Mendeley Data, 2020.
